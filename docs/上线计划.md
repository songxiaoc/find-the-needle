# Find the Needle 上线计划

- 来源：TomeWiki 模板；参考 Blood Dungeon 的 next-intl、OpenNext 静态缓存、Cloudflare Workers 部署方案。
- 语言：英语根目录，法语 `/fr`、德语 `/de`、西班牙语 `/es`、俄语 `/ru`。同页手动切换，语言检测仅作可关闭提示。
- 内容：首页、三篇实用指南、指南分类、FAQ、系统要求、排障与站点信任页面。先核实 Steam 正式版和 Demo 的边界，不发布模板样例和空数据库。
- 资料：Steam 官方商店和公告；图片保留来源，以本地压缩文件提供。正式版当前计划 Q4 2026，Demo 已发布。
- 域名：Spaceship NS 切到 Cloudflare，Workers 绑定 apex 与 www，www 重定向到 apex，开启 HTTPS。
- 发布：创建独立 GitHub 仓库，推送对应提交，经 Linux CI 检查及 OpenNext 构建后部署。
- 验收：五语言原始 HTML、metadata、互惠 hreflang、sitemap、404、素材、移动端导航和语言切换；生产提交与构建产物一致。
- 此任务不提交 GSC/IndexNow，不复用 Blood Dungeon 的广告或统计 ID。
