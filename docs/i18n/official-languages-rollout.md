## 结构与交互

沿用共享页面组件、现有页面和内容结构、素材、业务事实及站内 slug；仅翻译可见文案。语言选择器、浏览器语言提示、偏好记忆与现有网站保持一致，不增加强制跳转。中文使用 `/zh`，hreflang 使用 `zh-CN`；巴西葡萄牙语使用 `/pt`，hreflang 使用 `pt-BR`。

新增文案放在每种语言独立的 JSON 包内，公开语言以 `src/generated/site-locales.ts` 为唯一清单。生产只包含本次新增中文文件；备用分支具备所有语言的资源和构建配置，仅保存源码，不执行部署。

## 发布及后续操作

1. 先集成中文资源，完成格式、类型、lint、站点校验、工具测试和生产构建；检查原始 HTML 与桌面、移动端关键交互。
2. 中文代码同步推送 `main`，通过既有 GitHub Actions 发布 Cloudflare Worker，核对线上中文页、Sitemap 234 个 URL、原有语言及未发布语言 404。
3. 从中文生产提交创建 `codex/all-official-locales`，保存其余 6 种完整翻译，完成全语言构建后推送该分支。该分支不会触发仅绑定 `main` 的生产流水线。
4. 后续批次从备用分支选取目标语言的攻略、实体和文案包、common 消息；增加目标语言的包导入和公开语言清单。不得直接合并备用分支，以免所有语言同时公开。
5. 每次发布检查目标语言 39 页、导航、语言提示、canonical/hreflang、Sitemap、llms.txt 和之前已发布语言；非本批次语言保持 404。

## 验收边界
