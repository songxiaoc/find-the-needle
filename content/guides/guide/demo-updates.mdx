**Demo V8 changed conveyor placement, electricity feedback and loose-hay performance.** Its official notes were posted on **September 11, 2026 UTC**. This is a summary of that documented update, not a claim that V8 is today's installed build. News checked October 4, 2026.

As of October 4, 2026, the official Steam news feed still ends with the September 25 popularity announcement. No newer public gameplay patch notes were found in that feed. The full game remains planned for Q4 2026, with no exact release day listed. For the documented belt and power changes, use the V8 summary below.

## Changes that affect your factory

| V8 change | What to do in your setup |
| --- | --- |
| Belts snap to the Hay Sell Stand; placement gained automatic pathfinding | Recheck the final connection when a belt reaches the stall but sales do not happen. |
| F activates No Snap mode | Use the placement mode that fits the route, then test the connection with material. |
| E at a power pole can shut down the whole grid | Check the grid state if several machines stop after you use a pole. |
| Low-power visual notification | Read the electricity warning before replacing an idle machine. |
| U-Splitters and U-Joiners added | Inspect the available junctions when arranging parallel lanes. |
| Pellet Disc Machine gained BRICKS / HAY indicators | Check which input the machine is waiting for. |

For the working sequence, see [connecting belts and power](/guides/guide/automation).

## Performance and purchase changes

The update groups loose hay on the ground into clusters to improve frame rate. It also raises the default jump height, adds in-game tips and mentions further bug fixes without listing every fix individually. It does not name a fix for the reported 5/6 missing-needle situation.

**Vacuum Yard was reduced in price by 80% in V8.** That is a historical price change, not a current price quote. Compare the amount shown in your own game before planning a purchase around an older video.
