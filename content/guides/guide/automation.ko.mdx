첫 라인을 가동하려면 건초 공급원과 목적지를 연결하고 필요한 곳에 전력이 있는지 확인한 뒤, 재료를 흘려보내고 나서 분기를 추가하세요. **Demo V8에는 <EntityLink kind="machines" id="hay-sell-stand">Hay Sell Stand</EntityLink> 스냅, F 키의 No Snap 모드, 전봇대에서 E 키로 전력망을 끄는 상호작용이 추가되었습니다.** 연결된 것처럼 보이지만 작동하지 않을 때 유용한 정보입니다.

## 판매 쪽 끝부터 연결하세요

![건초 더미 옆에서 SELL HAY 표시가 있는 판매대까지 컨베이어가 이어집니다.](/images/find-the-needle/screenshot-1.webp)

이 공식 스크린샷의 목적지는 **SELL HAY** 판매대입니다. V8 업데이트는 이곳에 벨트 스냅을 추가하고 자동 경로 탐색으로 컨베이어 배치를 개선했습니다.

1. 판매 지점을 찾고 접근할 공간을 남기세요.
2. 판매대의 스냅 연결을 사용해 마지막 벨트 구간을 놓으세요.
3. 운반할 공급원이나 기계 출력 쪽으로 상류를 연결하세요.
4. 소량을 투입해 판매 지점까지 따라가세요. 돈 표시가 바뀌는지도 확인하세요.

원하지 않는 곳으로 계속 스냅된다면 V8 설명에 따라 **F 키로 No Snap 모드를 켜세요**. 배치 방식을 바꿀 때 게임의 모드 표시와 안내를 확인하세요. 자유 배치는 레이아웃 조정에 도움이 되지만 두 끝이 실제로 연결됐다는 증거는 아니므로, 배치 후 재료 흐름을 시험하세요.

## 전기 기계 여러 대가 함께 멈출 때

기계를 교체하기 전에 공용 전력 공급을 확인하세요. V8에서는 **전봇대에서 E 키를 눌러 전력망 전체를 끌 수 있습니다**. 전봇대를 조작한 뒤 여러 기계가 멈췄다면 먼저 전력망 상태를 살피고, 전봇대의 현재 안내에 따라 복구하세요.

같은 업데이트에는 전력이 필요량보다 적을 때 시각 알림이 추가되었습니다. 벨트가 건초를 전달한다고 기계에 전력이 충분한 것은 아닙니다. 재료 경로를 바꾸기 전에 전력 표시를 읽으세요.

## 건초가 처음 멈추는 지점을 찾으세요

| 관찰한 현상 | 다음 확인 사항 |
| --- | --- |
| 입력 벨트가 비어 있음 | 수집기나 이전 기계까지 경로를 거슬러 확인하세요. |
| 건초는 도착하지만 다음 기계가 멈춰 있음 | 전력, 필요한 입력 재료, 기계의 출력 경로를 확인하세요. |
| 스캐너 앞에 대기열이 생김 | 스캐너 처리 속도가 재료 도착 속도보다 느린지 보세요. |
| 재료가 분기점에 도착하지만 목적지로 가지 않음 | 판매대 경로를 포함해 각 출력 분기를 따로 추적하세요. |

이 점검은 문제를 좁히는 방법이며, 멈춘 모든 기계의 원인이 같다는 보장은 아닙니다. V8은 **<EntityLink kind="machines" id="pellet-disc-machine">Pellet Disc Machine</EntityLink>**에 **BRICKS / HAY** 자원 표시를 추가했습니다. 가득 차 보이는 벨트가 모든 필요 재료를 제공한다고 생각하지 말고 표시를 확인하세요.

## 바늘 검사를 우회하지 않고 확장하세요

V8에는 **<EntityLink kind="machines" id="u-splitter">U-Splitters</EntityLink>**와 **<EntityLink kind="machines" id="u-joiner">U-Joiners</EntityLink>**가 도입되었습니다. 스캐너 혼잡을 논의한 플레이어들은 별도 스캔 라인으로 분리한 뒤 출력을 합치는 방법도 제안했습니다. 이는 커뮤니티의 배치 제안이지, 측정된 처리량 보장이 아닙니다. 공장 전체로 복제하기 전에 각 라인을 시험하세요.

모든 제품의 바늘을 검사하려면 판매 지점으로 가는 **모든** 경로가 스캔 설비를 통과하는지 추적하세요. 다른 분기가 우회한다면 깔끔한 주 라인만으로는 부족합니다. 건초 제품 속 바늘에 대한 개발자 설명은 [바늘과 스캐너](/guides/guide/needles-and-scanners)를 참고하세요.

멈춘 경로를 다시 만들기 전에 [라인 점검](/tools/line-check)으로 공급, 전력, 출력, 스캐너 검사 범위를 순서대로 확인하세요.
