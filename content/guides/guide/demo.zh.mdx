## 检查电脑配置

Steam 页面标明适用于 Windows。Demo 公布的配置要求如下：

| 部件 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Windows 10，64 位 | Windows 11，64 位 |
| 处理器 | Intel i5-8400 或 Ryzen 5 2600 | Ryzen 5 5600 或 Intel i5-12400 |
| 内存 | 8 GB RAM | 16 GB RAM |
| 显卡 | 独立显卡，Vulkan 1.3，4 GB 显存；GTX 1050 Ti 或 RX 570 | GTX 1660 Super 或 RTX 2060，6 GB 显存 |
| 存储空间 | 2 GB 可用空间 | 2 GB 可用空间 |

开发者提醒，集成显卡不受支持，可能导致崩溃。大型工厂也会增加 CPU 负载。达到表列配置并不保证获得某个特定帧率。

## 备份 Demo 存档

开发者在 Steam 回复中给出了以下 Windows 存档目录：

```text
%APPDATA%\Godot\app_userdata\Haystack Incremental\saves
```

1. 使用游戏中提供的操作保存进度，然后关闭游戏。
2. 按 **Win + R**，粘贴上面的路径，再按 Enter。
3. 将整个 **saves** 文件夹复制到其他位置。给副本标上日期，方便与旧备份区分。

请复制文件夹，并把原文件夹留在原处。如果 Windows 找不到目录，请在玩游戏所用的 Windows 账户下检查路径。这只是本地备份方法，不代表游戏支持 Steam Cloud 或跨版本存档迁移。

**Demo 存档能继承到完整版吗？** 在 9 月 27 日核查的来源中，未找到经过验证的官方确认。请保留备份，但不要默认兼容正式版。

存档位置：[开发者回复](https://steamcommunity.com/app/5160800/discussions/0/563667940587675789/)。如果找针数量停滞，拆除设备前先查看[筒仓与扫描器检查](/guides/guide/needles-and-scanners)。
