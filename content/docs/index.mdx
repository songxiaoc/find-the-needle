This docs index is a [Fumadocs](https://fumadocs.dev) MDX section, separate
from the curated `/guides` pages. It is intended for reference material that
reads better as structured documentation.

## What you'll find

- **System guides** — explanations of game systems written in MDX.
- **Reference** — stable material that benefits from documentation navigation.

## Adding a doc

1. Drop a new `.mdx` file in `content/docs/`.
2. Add its slug to `content/docs/meta.json` to set the sidebar order.
3. Give it `title` and `description` frontmatter for SEO.

See [the example doc](/docs/example-doc) for the supported structure.

## Sourcing policy

Every factual claim should come from an official source or a verified in-game
screen. Link to [the About page](/about) for the full editorial rules.
